# Coffee_Sales_powerpivot_modelanalysis
Excel Power Pivot project analyzing coffee sales from 2019 to 2022. Built a relational data model linking orders, customers, and products, then used DAX measures and PivotTables to track profit by year, month, roast type, and coffee type (Arabica, Excelsa, Liberica, Robusta). Flags returning customers and ranks them by profit per order.
